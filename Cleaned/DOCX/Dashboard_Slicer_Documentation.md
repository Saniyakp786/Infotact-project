# Dashboard Slicer Documentation

## 1. Purpose
- Added slicers to make the dashboard interactive.
- Allows users to filter shipment data.
- Helps analyze specific shipment categories.

## 2. Slicer Details

### Transport Mode Slicer
- Column: transport_mode
- Filters shipments by Sea, Air, Truck, and Rail.
- Helps compare shipment data across transport modes.

### Cargo Type Slicer
- Column: cargo_type
- Filters data according to cargo categories.
- Helps analyze spoilage risk for selected cargo types.

## 3. Benefits
- Makes the dashboard interactive.
- Helps users focus on specific data.
- Improves data analysis and user experience.
- Updates connected visuals according to the selected filters.
