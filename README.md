# AtmoSync

AtmoSync: Micro-Climate Arbitrage Analytics

An analytics pipeline for monitoring real-time environmental conditions in intermodal rail transportation and identifying spoilage risks.

## Dataset

Intermodal Rail shipment dataset.

## Pipeline

CSV → Python/Jupyter → Kafka → Snowflake → dbt → Apache Superset

## Main KPIs

- Total Shipments
- Average Spoilage Risk
- High Risk Shipments
- Average Temperature
- Average Humidity
- Average Remaining Shelf Life
