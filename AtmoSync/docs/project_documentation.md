# AtmoSync Air Freight Project

## Project Overview

AtmoSync analyzes micro-climate conditions affecting Air Freight shipments.

## Data

Air Freight shipment dataset.

## Technologies

- Python
- Jupyter
- Pandas
- Kafka
- Snowflake
- dbt
- Apache Superset

## Pipeline

Air Freight
→ Python
→ IoT Simulator
→ Kafka
→ Snowflake
→ dbt
→ Superset

## Analytics

- Temperature Analysis
- Humidity Analysis
- Vibration Analysis
- Spoilage Risk
- Remaining Shelf Life
- At-Risk Shipments
- KPIs

## Dashboard

The Superset dashboard provides operational monitoring of Air Freight shipment conditions.

## Team Integration

The Air Freight dataset will later be combined with Sea Freight, Road Freight and Rail Freight datasets prepared by the other team members.

## Future Business Analysis

The final merged dataset can be used for team-level Power BI business analysis.
