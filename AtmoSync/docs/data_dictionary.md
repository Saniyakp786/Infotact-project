# AtmoSync Air Freight Data Dictionary

| Column | Description |
|---|---|
| shipment_id | Unique shipment identifier |
| transport_mode | Transportation method |
| recorded_date | Date of observation |
| recorded_time | Time of observation |
| recorded_datetime | Combined date and time |
| origin_location | Shipment origin |
| destination_location | Shipment destination |
| cargo_type | Type of cargo |
| temperature_celsius | Recorded temperature |
| humidity_percentage | Recorded humidity |
| vibration_level | Container vibration measurement |
| pressure_kpa | Container pressure |
| exposure_duration_hours | Environmental exposure duration |
| door_open_count | Number of container door openings |
| salinity_ppt | Salinity measurement |
| thermal_leakage_score | Thermal leakage indicator |
| spoilage_risk_percent | Estimated spoilage risk |
| remaining_shelf_life_days | Estimated remaining shelf life |
| spoilage_status | Spoilage condition/status |
